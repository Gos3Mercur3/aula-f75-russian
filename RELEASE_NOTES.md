## Что это

Русская версия интерфейса утилиты AULA F75 (OemDrv / BYCOMBO4). Меняется только текст: 270 надписей.
В прошивку клавиатуры не пишется ничего.

## Файл для скачивания

`AULA_F75_RU_installer.zip` (33 673 байта). Распаковать **целиком** → двойной клик `УСТАНОВИТЬ.bat`
→ перезапустить утилиту полностью (трей → ПКМ → Выход). Откат — `undo.bat`, оригинал лежит рядом
как `text.xml.bak`.

Работает с AULA F75 / F75 Pro / F75 Max / F87 / F99 на этом же движке. Русский ставится во все
папки языка сразу, так что выбор языка в меню больше ни на что не влияет.

## Проверено

25 автотестов, все зелёные: XML и кодировка (UTF-16 LE + BOM + CRLF), порядок тегов 1:1 с
английской сборкой, 7 пустых строк совпадают с оригиналом, ни одного иероглифа, батники без
битых меток и без `del`/`rd`, бэкап создаётся до записи и не затирается при повторных запусках,
симуляция установки/откатa на фиктивной папке `Text\en\`, раунд-трип `dist/` == пересборка из
`tools/ru.json`.

## Не проверено (и не может быть проверено на Linux-раннере)

Двойной клик по `.bat` в настоящем `cmd.exe` и внешний вид `OemDrv.exe`. На живой F75 перевод
отображается корректно (кириллица есть, квадратиков нет) — это проверял пользователь на Windows.
